# Tasks

This folder contains approved implementation task files for the Jojo app.

Each task should have one matching report in `docs/reports/` using the same filename slug.

Example:

```text
docs/tasks/phase-9e-example.md
docs/reports/phase-9e-example.md
```

Use `docs/backlog/` for rough ideas. Promote only approved work into `docs/tasks/`.

Task files should include goal, current state, required behavior, out-of-scope items, safety restrictions, validation steps, and expected report path.
