# The app gives no medical advice, growth interpretation, or dosage guidance

Jojo's Log is a care ledger, not a medical tool. It records what happened; it does not tell parents what should happen. This is a hard product boundary, not just a safety precaution: the app's value comes from being a calm, factual record that caregivers trust precisely because it does not second-guess them.

Concretely, this means:
- No "your baby should be eating X mL at this age" language
- No dosage guidance for Vitamin D or any medication
- No growth percentile interpretation
- No sleep coaching
- No milestone tracking
- Medication is a simple boolean flag; details go in the Notes field
- Vitamin D is a simple boolean flag; no recommended schedule is shown
- The Weekly Usual Bottle Amount is a caregiver-entered value, not a system suggestion

The words "target", "recommended", "goal", and "should" are banned from all UI copy in the context of care amounts.
